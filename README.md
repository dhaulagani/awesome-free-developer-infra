## 🤖 How the Autonomous Verification Engine Works
This repository is maintained automatically by a background worker daemon:
1. Every 24 hours, an automated runner sends latency and handshake probes to each provider's documentation and dashboard endpoint.
2. Providers with changed or deprecated free tiers are flagged and updated.
3. Live badges and latency benchmarks (`ms`) are re-computed and committed directly to `main`.
